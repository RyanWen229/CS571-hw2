\section*{I. Supervised Entity Tagging}

\textbf{Task and protocol.}
I treat named-entity recognition as token-level BIO classification over the six
Re-DocRED types: PER, ORG, LOC, TIME, NUM, and MISC.  The model is trained only
on the 3,053 documents in \texttt{train\_revised.json}.  The 500-document dev
split is used for feature and hyperparameter selection.  After fixing every
choice, I run the model once on the 500-document test split.  Evaluation is at
the mention-span level: a prediction is correct only when sentence index,
start, end, and type all exactly match a gold mention.  Thus every span, rather
than every coreference cluster, contributes one item to micro precision,
recall, and F1.

\textbf{Model and features.}
The tagger is an averaged multiclass linear classifier trained with stochastic
gradient descent and log loss.  Sparse categorical features are mapped with
\texttt{FeatureHasher}; this bounds memory and avoids learning a separate
vocabulary.  For token $w_i$, the representation contains:
\begin{itemize}
  \setlength\itemsep{-0.18em}
  \setlength\topsep{0.05em}
  \item the original and case-folded token, compressed character shape,
        capped length, and indicators for uppercase, title case, lowercase,
        digits, embedded digits, hyphens, and alphanumeric form;
  \item all case-folded prefixes and suffixes of lengths 1--5;
  \item case-folded token and shape features from a $\pm3$ token window,
        explicit sentence-boundary markers, and left/right lexical bigrams;
  \item the preceding BIO tag (gold during training and predicted during
        decoding), which gives the otherwise local classifier sequence context.
\end{itemize}
When gold spans overlap, longer spans are assigned first and later conflicts
are skipped so that each sentence has one valid BIO sequence.  At inference,
orphaned I-tags are repaired to B-tags.  Repeated mentions with the same type
and normalized surface string are grouped into one Re-DocRED entity; grouping
does not affect mention-level evaluation.

\textbf{Selected hyperparameters.}
The final classifier uses 524,288 hashed dimensions, L2 regularization with
$\alpha=10^{-6}$, at most 20 epochs, convergence tolerance $10^{-3}$, averaged
weights, and random seed 571.  Because O tokens dominate the corpus, they
receive sample weight 0.60 while entity tokens receive weight 1.00.  The loss
is one-vs-rest logistic loss; feature-hash signs are nonnegative.  These are the
defaults in \texttt{ner\_predict.py}, while command-line options expose all
of these settings for reproducible experiments.

\subsection*{Error analysis}
For analysis only, unmatched gold and predicted spans are paired one-to-one.
Exact-boundary pairs with different types are paired first; remaining
overlapping pairs are matched by same type and then token intersection-over-
union.  On test there are 2,766 paired near misses: 1,780 type-only errors,
600 boundary-only errors, and 386 with both errors.  Consequently 35.6\% of
paired near misses involve a boundary error and 78.3\% involve a type error
(the categories overlap).  A further 464 gold mentions are completely missed
and 435 predictions are spurious.  Among the 986 boundary-involved pairs, 567
are too narrow, 412 too wide, four shifted, and three mixed.

The largest directed confusion is ORG$\rightarrow$LOC (333), followed by
MISC$\rightarrow$LOC (309).  MISC also disperses into PER and ORG, which is
consistent with its heterogeneous semantic role.  LOC recall is high but its
false positives reduce precision, while ORG exhibits the opposite recall
problem.  TIME/NUM confusions reflect date-like and quantity-like expressions.
The high share of too-narrow spans suggests that local lexical evidence often
finds an entity head but omits modifiers; stronger structured decoding or a
span-level model would be a natural next improvement.
